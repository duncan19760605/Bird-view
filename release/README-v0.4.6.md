# 走，賞鳥趣 v0.4.6

## 安裝檔

- Windows：`BirdView-Setup-v0.4.6.exe`
- Android：`BirdView-v0.4.6.apk`（versionCode 6，與先前版本同一簽章，可直接覆蓋安裝）

## 本版內容

- 更正超聲波頻率：7 號（左下）改為 21500 Hz、9 號（右下）改為 22990 Hz（原本輸入時對調了）。其他格不變，地墊不需更動。
  - 參考音檔 `button-07.wav`、`button-09.wav` 的檔名原本也標反，已對調並重新產生 `protocol.json`。
  - 玩家裝置上若仍存著舊的錯誤頻率，開啟遊戲時會自動更正，並把這兩格的閾值改回預設；請重新做一次「一鍵引導校正」。
- 背景音樂與鳥鳴音量放大為 3 倍（同一個滑桿位置，例如預設 60%，聲音是 v0.4.5 的 3 倍）。
